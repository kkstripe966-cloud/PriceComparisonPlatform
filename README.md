# PriceComparisonPlatform

今天吃点啥 Pro 



基于 SSM 与 Vue.js 的外卖比价平台



项目功能



本项目是为高校学生打造的餐饮决策辅助系统，旨在通过技术手段解决“吃什么”和“怎么买划算”的痛点。核心解决了多平台外卖价格不透明、餐饮信息过载以及选择困难症三大问题，提供从浏览、比价到决策的一站式服务。



架构简介



项目采用标准的前后端分离架构，确保系统的可维护性与扩展性。

后端：基于 Spring Boot + MyBatis (SSM) 构建，提供 RESTful API 接口，负责业务逻辑处理、数据库交互及安全认证（JWT）。

前端：基于 Vue.js 3 构建，通过组件化开发实现响应式界面，利用 Axios 与后端进行异步数据交互。

数据：采用 MySQL 8.0 存储核心业务数据，包括用户信息、菜品数据及多平台价格记录。



核心功能



1\.  智能比价引擎 

&#x20;   自动计算并对比美团、饿了么等平台的“到手价”（含满减、优惠券、配送费），提供价格预警与更具性价比的替代推荐。

2\.  美食盲盒 

&#x20;   结合系统时间（白天/夜晚模式）与用户预算，通过随机算法推荐餐品，增加用餐趣味性。

3\.  个性化推荐 

&#x20;   基于热度与用户行为数据，在首页聚合展示热门菜品与分类导航，支持关键词智能搜索。
